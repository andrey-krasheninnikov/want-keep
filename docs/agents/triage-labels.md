# Triage labels

| Role | GitHub label | Meaning |
| --- | --- | --- |
| needs-triage | needs-triage | Awaiting evaluation |
| needs-info | needs-info | Missing information or required evidence |
| ready-for-agent | ready-for-agent | Specified for implementation |
| ready-for-human | ready-for-human | Requires human judgment or participation |
| wontfix | wontfix | Rejected work |

Use exactly one triage state and one category: bug or enhancement.
Preserve unrelated labels.

Readiness describes the next kind of work. Open blocking dependencies
and unmet entry conditions still prevent execution.
