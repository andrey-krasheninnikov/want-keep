# Компоненты Want Keep

[English](design-components.en.md) · [Дизайн](design.md) · [task-7.16](tasks/task-7.16.md)

## Назначение и владение

D-49: `@want-foundation/desyst-foundation` и `@want-foundation/desyst-react` закреплены на 0.2.1. Общая библиотека владеет Radix-примитивами, CSS, шрифтами, фокусом и motion. Want Keep использует публичные exports и собранные ресурсы; исходники библиотеки не копируются и не сканируются Tailwind. Проектный `want-design` установлен из того же пакета.

Локальный design-system содержит только продуктовые композиции, безопасные значения по умолчанию и адаптацию публичных props. API, маршруты, финансовые расчёты, хранение и локализация остаются в features. Старые Base UI, DayPicker, shadcn и самостоятельный календарь удалены. Это одна реализация интерактивных примитивов.

## Карта миграции и интерфейсы

| Локальный интерфейс | Общий компонент / сохранённое продуктовое поведение |
| --- | --- |
| Button | Общий Button; primary/md отображаются в default/default. Тип по умолчанию button, submit задаётся явно. Ссылки используют asChild с единственным дочерним элементом. Ref, disabled, loading и callbacks проходят через публичные props. |
| ActionTile | Композиция Button с иконкой и текстом; ссылка задаётся href. Не принимает маршрут или финансовую команду из библиотеки. |
| Input / Textarea / MoneyField | Общие Input/Textarea. onValueChange получает исходную строку. MoneyField добавляет актив и decimal inputMode, без Number, обрезания или скрытой нормализации. |
| Form / Field / FieldLabel / FieldDescription / FieldError | Нативная форма и общие Field-компоненты. Продуктовая композиция связывает label, control и реально показанные описания/ошибки через уникальные ID. Required-проверка остаётся нативной, денежная и предметная валидация у вызывающего кода. |
| FieldGroup / FieldSet / FieldLegend | Прямые публичные exports. |
| Select | Общие Select/Trigger/Value/Content/Item. Опции, disabled, null/placeholder и локализованное имя остаются props; порталы и клавиатуру реализует Radix. |
| Combobox | Общий controlled Combobox, с явными label/options/emptyLabel; nullable выбор отображается в пустую строку. Каталог не назначает финансовую категорию. |
| DateField / CalendarDate | Общий DateField 0.2.1 выбирает день. Локальная композиция сохраняет ручной RU/EN ввод, пустой/невалидный/валидный черновик и ошибку. CalendarDate преобразует календарные строки без сдвига даты. Самостоятельного календаря и DayPicker нет. |
| Checkbox / RadioGroup / RadioItem / Switch / Tabs | Общие компоненты; RadioItem является именем публичного RadioGroupItem. Состояние принадлежит вызывающему коду. |
| ToggleGroup / ToggleItem | Небольшая композиция общих Button для выбора представления бюджета: aria-pressed, одна Tab-точка, стрелки/Home/End, контролируемый выбор. Это не отдельный примитив библиотеки. |
| Dialog / Sheet | Публичные диалоги, заголовки, описания и локализованные closeLabel. Композиция добавляет содержимое продукта, не реализуя собственный focus trap или portal. |
| AlertDialog | Подтверждение поверх общего Dialog: role=alertdialog, без неявного закрытия снаружи и без дополнительной кнопки X; безопасное действие идёт первым. |
| Popover / Tooltip | Общие overlays и triggers; локальная композиция связывает заголовок Popover с доступным именем. Переключение языка задаёт язык документа, включая порталы. |
| Table / TableHead / TableCell | Общая семантическая таблица в области прокрутки. Подготовленные значения и серверные фильтры принадлежат потребителю. |
| Pagination | Две общие Button, summary и доступность направлений. Сохраняется keyset-контракт без выдуманного total или номера последней страницы. |
| Surface / Badge / Alert | Общие Card/Badge/Alert, с продуктовым содержимым и семантическими статусами. Alert объявляет изменение только при announce; цвет не заменяет текст. |
| Toast / Toaster | Общий ToastProvider и Toast-компоненты. Локальная очередь ограничена тремя сообщениями, duration 8 секунд; закрытие, pause и доступность сохраняются. Важный результат остаётся на экране. |
| Skeleton / Progress | Общие индикаторы. Progress получает готовое значение или null и локализованное объяснение. Нет денежного расчёта или подмены unknown нулём. |
| Avatar / Empty / ListItem / Sidebar | Продуктовые композиции содержимого и навигации. Avatar сохраняет имя и fallback инициалов при ошибке изображения; SideBar получает готовые ссылки и currentId. |
| ChartLegend / ChatResult | Композиции общих Checkbox/Badge и подготовленного содержимого. Они не считают доходность, не применяют предложения и не меняют principal. |

## Состояния и доступность

`/__design/components` показывает UISTATE-01–17 только на синтетических данных. Loading, disabled, saving, unknown-result, conflict, session-expired и confirmed не меняют своего смысла. Unknown запрещает повторный эффект и сохраняет черновик; конфликт не уничтожает ввод; истечение сессии скрывает чувствительные данные. Общие компоненты не принимают финансовые решения.

Сохраняются labels, helper/error association, native form semantics, controlled state, refs, keyboard, focus trap/restore, вложенные overlays и отсутствие случайного submit. Применяется общий контрастный focus outline, а не прежняя инверсия. Status-text используется только на разрешённых поверхностях. Reduced motion/transparency и cleanup принадлежат общей реализации и продуктовым эффектам.

Дата поддерживает 0001-01-01…9999-12-31. При смене языка корректный день форматируется заново, некорректный текст остаётся для исправления. Все шесть активов и длинные дробные суммы сохраняются строками. Источник, серверные роли и автор команды не зависят от выбранного визуального представления.

## Проверки и передача

Web unit/typecheck/lint/build, design-tokens/design-components/access browser suites и docs-check подтверждаются отдельно. Chrome и Arc не считаются проверенными по одному запуску Chromium. Снимки и traces хранятся вне репозитория; личные данные и настоящие банковские секреты не используются. Оба каталога исключаются из production bundle.
